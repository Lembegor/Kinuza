Kinuza for macOS plays video with libmpv and FFmpeg.

The libraries in Kinuza.app/Contents/Frameworks come unchanged from
media-kit/libmpv-darwin-build v0.7.3 (macos-arm64-video-full):
https://github.com/media-kit/libmpv-darwin-build/releases/tag/v0.7.3
Their source code and build scripts are available at that address.

They are linked dynamically, so each of them can be replaced with another
compatible build of the same library.

  libmpv (mpv 0.36, built with -Dgpl=false)      LGPL-2.1-or-later   https://mpv.io
  libavcodec, libavformat, libavfilter,

  built without --enable-gpl / --enable-nonfree) LGPL-2.1-or-later   https://ffmpeg.org
