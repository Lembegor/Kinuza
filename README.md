# Kinuza

Настольное приложение для Windows: каталог фильмов, сериалов и аниме (постеры, описания, списки серий) и плеер, который воспроизводит торрент-файлы прямо во время загрузки.

- Каталог и поиск — TMDB, на русском.
- Источник видео — magnet-ссылка или `.torrent`-файл, которые вы добавляете сами: вставьте ссылку (Ctrl+V) или перетащите файл в окно. Для сериалов файлы раздачи автоматически раскладываются по сезонам и сериям, разбор можно поправить вручную.
- Свободные копии: для фильма диалог добавления сам ищет его в Internet Archive (фильмы в общественном достоянии и под свободными лицензиями) и добавляет выбранную копию в один клик.
- Ссылки из браузера: Kinuza может стать программой для magnet-ссылок и `.torrent`-файлов. Клик по ссылке открывает приложение с готовым диалогом — название тайтла подбирается по имени раздачи. Включается вопросом при первом запуске или в настройках; при выключении возвращается прежняя программа.
- Мой список: статусы «Смотрю», «Запланировано», «Просмотрено», «Отложено», «Брошено» и своя оценка от 1 до 10. Статус сам становится «Смотрю», когда вы начинаете смотреть, и «Просмотрено», когда досмотрен фильм или все серии. Сезон можно отметить просмотренным одной кнопкой.
- Плеер: просмотр во время загрузки, выбор качества между добавленными источниками и качество по умолчанию в настройках, звуковые дорожки, субтитры (из раздачи или из файла, с названиями языков), скорость, продолжение с места остановки, следующая серия.
- Автообновление: приложение само находит новую версию, скачивает подписанный установщик и перезапускается.

Стек: Tauri 2 (Rust) + React + TypeScript, торрент-движок `librqbit`.

## Запуск для разработки

Нужны Node.js 22+, Rust (stable, MSVC) и WebView2 (в Windows 11 уже есть).

```bash
npm install
```

Скопируйте `.env.example` в `.env` и впишите ключ TMDB (API Key v3). Файл `.env` в git не попадает.

```bash
npm run app:dev
```

Только интерфейс в браузере, с заглушкой вместо торрент-движка:

```bash
npm run dev
```

## Как раздать друзьям

1. Соберите установщик:

   ```bash
   powershell -ExecutionPolicy Bypass -File scripts/release.ps1 -Version 0.1.0 -Notes "Первая версия"
   ```

   Результат — папка `release/v0.1.0`: установщик `Kinuza_0.1.0_x64-setup.exe` и `latest.json`.
2. Создайте публичный репозиторий `Lembegor/Kinuza` на GitHub, в нём релиз с тегом `v0.1.0`, приложите оба файла.
3. Отправьте друзьям ссылку на установщик. Он ставится без прав администратора.

При первом запуске Windows покажет два окна, это ожидаемо:

- **SmartScreen** («Система Windows защитила ваш компьютер») — установщик не подписан платным сертификатом. Нажать «Подробнее» → «Выполнить в любом случае».
- **Брандмауэр** — запрос на доступ к сети для обмена с участниками раздач. Нужно разрешить.

## Как выпустить обновление

Один раз: `winget install GitHub.cli`, затем `gh auth login`.

```bash
powershell -ExecutionPolicy Bypass -File scripts/release.ps1 -Version 0.2.0 -Notes "Что изменилось" -Publish
```

Скрипт поднимает версию, собирает и подписывает установщик, создаёт `latest.json` и публикует релиз. Приложения друзей при следующем запуске покажут карточку «Обновить и перезапустить». Без `-Publish` скрипт только собирает файлы — их можно приложить к релизу вручную.

Альтернатива без локальной сборки — GitHub Actions (`.github/workflows/release.yml`): добавьте в репозиторий секреты `TAURI_SIGNING_PRIVATE_KEY` (содержимое файла ключа) и `VITE_TMDB_API_KEY`, поднимите версию в `package.json`, запушьте тег `v0.2.0` — релиз соберётся и опубликуется сам.

### Ключ подписи обновлений

Обновления подписываются ключом `%USERPROFILE%\.tauri\kinuza.key`; публичная часть вшита в приложение (`src-tauri/tauri.conf.json`). **Сделайте резервную копию этого файла и никому его не передавайте.** Если ключ потерять, уже установленные приложения не примут ни одно обновление — друзьям придётся ставить новую версию вручную.

Адрес, по которому приложение ищет обновления: `https://github.com/Lembegor/Kinuza/releases/latest/download/latest.json`. Если репозиторий называется иначе, поменяйте адрес в `tauri.conf.json` и параметр `-Repo` скрипта до первой раздачи.

## Устройство

| Что | Где |
|---|---|
| Торрент-сессия, добавление и список загрузок | `src-tauri/src/engine.rs` |
| Локальный сервер, отдающий файлы плееру с поддержкой Range | `src-tauri/src/server.rs` |
| Команды для интерфейса | `src-tauri/src/commands.rs` |
| Регистрация magnet и `.torrent` в Windows (HKCU), возврат прежней программы | `src-tauri/src/associations.rs` |
| Разбор ссылки или файла из аргументов запуска | `src-tauri/src/launch.rs` |
| Клиент TMDB | `src/lib/tmdb.ts` |
| Поиск свободных копий в Internet Archive | `src/lib/archive.ts` |
| Разбор качества и номеров серий из имён файлов | `src/lib/parse.ts` |
| Полка, источники, прогресс просмотра | `src/state/library.ts` |
| Плеер | `src/components/Player.tsx` |
| Диалог добавления торрента | `src/components/AddSourceDialog.tsx` |

Данные пользователя лежат в `%APPDATA%\com.lembegor.kinuza` (полка, настройки, состояние загрузок); скачанные файлы по умолчанию — в `Видео\Kinuza`.

Форматы: встроенный плеер использует декодеры WebView2 (H.264, HEVC, VP9, AV1; AAC, MP3, Opus, FLAC, AC-3). Файл с неподдерживаемым видео или звуком можно одним нажатием открыть во внешнем плеере (mpv, VLC, MPC), если он установлен.

Постеры, описания и списки серий предоставлены TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB.
